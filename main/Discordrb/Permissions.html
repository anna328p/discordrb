Constructor Details

#initialize(bits = 0, writer = nil) ⇒ Permissions

Create a new permissions object.

Examples:

Create a new permissions object for a list of specific permissions.

Permissions.new([:read_messages, :connect, :speak])

Create a blank permissions object and then add specific permissions.

permission = Permissions.new
permission.can_bypass_slowmode = true
permission.can_use_slash_commands = true
permission.can_send_messages_in_threads = true

Parameters:

  • bits (String, Integer, Array<Symbol, String>) (defaults to: 0) —

    The raw bitfield that should be initially set, or a collection of permission symbols.

  • writer (RoleWriter, nil) (defaults to: nil) —

    The role writer that should be used. This parameter is deprecated, and its usage is no longer encouraged.

def self.bits(collection)
  collection.reduce(0) { |sum, element| sum | MASKS[element.to_sym] }
end

def defined_permissions
  MASKS.filter_map { |name, value| @bits.anybits?(value) ? name : nil }
end
